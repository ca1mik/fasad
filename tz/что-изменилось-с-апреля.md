# Что было на видео и что есть сейчас

Сравнение по двум записям, которые вы видели в апреле. Всё ниже проверяемо —
можно пересмотреть видео и сверить.

---

## Видео от 2 апреля — «Industrial MVP»

Что на записи:

* интерфейс **на английском**: Dashboard, Clients, Leads, Orders, Production,
  Workers, Catalog, Templates, Materials, Stock, Admin;
* на сводке **везде нули**, а выручка подписана «REVENUE MOCK» — то есть
  заглушка, не настоящая цифра;
* статусы заказов английские: New, Calculating, Approved, Paid, Cutting, CNC,
  Manufacturing, Ready, Shipped, Cancelled;
* список заказов — **пустая таблица**;
* пользователи — демонстрационные, на `example.com`;
* карточка заявки показывает **сырой JSON прямо на экране**, а данные в нём про
  «Wardrobe Basic 600×1800×350» и «MDF Oak 16 mm» — про шкафы, не про фасады.

Это была работающая заготовка: структура есть, наполнения нет.

## Видео от 4 апреля — «Операционный контур»

Интерфейс уже русский, показан **экран раскроя листа**. За него и была названа
цена 200 000 ₽.

На записи видно:

* лист 2750×1250, отступы, общие зазоры 60/60;
* три алгоритма раскладки: **Оптимальный, По высоте, По ширине**;
* ввод деталей строками;
* на чистом раскрое сама подставлялась пустая деталь 280×280;
* заполнение листа 1,6 % — одна деталь на всём листе;
* в меню — «Каталог» и «Шаблоны».

## Что изменилось в самом раскрое — том, что вы смотрели

| | Апрель | Сейчас |
| --- | --- | --- |
| Алгоритмы | Оптимальный, По высоте, По ширине | **+ «Прижать влево»** — обрезки собираются в одну целую полосу |
| Поворот детали | галочка у каждой вручную | считается автоматически, берётся вариант с меньшим числом листов |
| Порядок укладки | один | **перебор шести порядков** и двух способов заполнения листа, остаётся лучший |
| Зазор у кромки листа | 60 мм упирались в пустоту и терялись | обрезаются по краю — детали влезают плотнее |
| Пустая деталь 280×280 | подставлялась сама на чистый раскрой | убрана, раскрой начинается пустым |
| Материалы | один на все детали | **каждый цвет — на свои листы**, лист же красят целиком |
| Ввод деталей | строками руками | **+ загрузка вашего `.xls`**: 37 позиций, 42 детали, 11,79 м² сами |
| Заявок за раз | одна | **сколько угодно** — отдельный экран с выбором, поиском и фильтрами |
| Выгрузка | SVG активной карты | **карты SketchCut, PDF всех листов, SVG по листу, бланк заказа в Excel** |
| Каталог и шаблоны | были в меню | убраны — у фасадов раскрой всегда индивидуальный, типовых изделий нет |

### Что это дало в цифрах

Ваш заказ Агат-Сервиса, 42 детали, зазор 60 мм:

| | Листов | Заполнение | Целая полоса справа |
| --- | --- | --- | --- |
| алгоритмом из апрельского видео | 7 | 50,8 % | 169 мм |
| **сейчас** | **6** | **59,2 %** | **2540 мм** |

Лист сэкономлен. И полоса выросла в пятнадцать раз: обрезки собрались на один
почти нетронутый лист вместо шести огрызков, которые только выбросить.

Шесть листов — предел: меньше не разложит никакая программа, площадь не
позволяет. Это посчитано, а не на глаз.

## Что появилось целиком, чего на видео не было вовсе

**Заявки.** Свои номера «З-0001», которые можно назвать клиенту по телефону.
Почта работает по-настоящему: система сама забирает письма и делает из них
заявки с вложениями, ответ менеджера уходит клиенту письмом.

**Загрузка вашего бланка.** Перетащили «Расчёт заказов.xls» — размеры, цвет,
толщина и фрезеровка вытащились сами. Система читает ваш бланк как есть: два
блока позиций рядом, колонку количества без заголовка, итоги и подписи внизу.

**Клиенты.** История заказов, суммы, давность. Типы: постоянный, активный,
новый, спящий, потерянный. Список «кто давно не покупал» — кому пора звонить.

**Заказы.** Номер сам получает букву направления: «0012», «0012-П», «0012-Ш»,
«0012-ОШ». Статусы, история переходов, создание из заявки одной кнопкой.

**Производство.** Маршрут по заказу, этапы, исполнитель и время, отчёты по
деталям с браком и фотофиксацией.

**Отчёты.** Объёмы за период в рублях **и в квадратных метрах**, по
направлениям и месяцам, «Принято / Отгружено». Для ПВХ материала считается
вдвое больше — плёнка клеится с двух сторон, система знает это сама.

**Ваши бумаги.** Бланк заказа — в точности ваш: заголовок про присадку «С ЛИЦА»,
таблица «№ / Длина / Ширина / Кол-во / М2 / Мм / Фрезеровка / Цвет», пустые
строки до 31-й, итоги, «Размеры проверил», «Заказ принял», адрес на Рахимова.
Площадь с пятью знаками — 0,70488, как у вас. Карты раскроя — в вёрстке
SketchCut, к которой привык цех.

**Склад, материалы, работники, права и журнал действий.**

## Подарок, который можно забрать прямо сейчас

Между деталями сейчас стоит зазор 60 мм. Это значение пришло из раскроя
ПВХ-плёнки, где нужен запас на облегание. Для эмалевой плиты, которую пилят,
столько не нужно.

Что даёт уменьшение на вашем же заказе:

| Зазор | Листов под эмаль 16 мм |
| --- | --- |
| 60 мм | 2 |
| 40 мм | 2 |
| 30 мм | 2 |
| **20 мм** | **1** |

При 20 мм весь материал ложится на один лист вместо двух. **Программу менять не
надо** — значение вводится в настройках листа. Проверьте со своим технологом:
экономия на каждом заказе.
