# ПРИЛОЖЕНИЕ № 1 к Договору № ___ от «___» _________ 20__ г.

## ТЕХНИЧЕСКОЕ ЗАДАНИЕ

Настоящее Приложение определяет состав работ, порядок их проверки и стоимость.
Формулировки составлены так, чтобы каждый пункт можно было **проверить в
присутствии Сторон и однозначно принять или отклонить**.

> Документ подготовлен Исполнителем. Перед подписанием подлежит проверке
> юристом Заказчика.

---

## 1. Общие положения

**1.1. Термины.**

| Термин | Значение в настоящем Договоре |
| --- | --- |
| **Система** | Программа для ЭВМ «Fasad Production Platform», разрабатываемая по Договору |
| **Заявка** | Запись о запросе клиента до создания заказа, имеющая собственный номер вида «З-0001» |
| **Заказ** | Запись о принятом в работу заказе, имеющая собственный номер с буквой направления |
| **Этап производства** | Отдельная операция производственного маршрута (раскрой, кромление, ЧПУ, сборка, контроль качества, упаковка) |
| **Работник** | Пользователь Системы с ролью «оператор» |
| **Рабочее место** | Компьютер или телефон с браузером, подключённый к Системе |
| **Рабочий день** | День с понедельника по пятницу, кроме нерабочих праздничных дней по ТК РФ |

**1.2. Среда проверки.** Все проверки настоящего Приложения выполняются на
Системе, установленной на оборудовании Заказчика (Этап 5), либо — до его
выполнения — на стенде Исполнителя, доступном Заказчику по сети.

**1.3. Признак выполнения пункта.** Пункт считается выполненным, если действие
из графы «Проверка» приводит к результату из графы «Результат» **при повторении
не менее двух раз подряд**. Разовое срабатывание выполнением не считается.

**1.4. Язык.** Весь интерфейс Системы, все сообщения об ошибках и вся
документация выполняются на русском языке.

**1.5. Браузеры.** Работоспособность обеспечивается в актуальных версиях Google
Chrome, Яндекс.Браузера и Safari на телефоне. Работоспособность в Internet
Explorer не обеспечивается.

**1.6. Ставка.** Стоимость каждого этапа рассчитана исходя из ставки
**2 500 (две тысячи пятьсот) рублей за час работ**. Количество часов по каждому пункту
указано в разделе 8.

| 2.2.5 | Администратор открывает экран настройки канала и нажимает «Проверить связь» | Отображается имя бота и признак успешного подключения |
| 2.2.6 | Администратор открывает экран настройки канала | Токен бота не отображается в открытом виде |

## 10. Обязанности Заказчика, влияющие на срок

**10.1.** Заказчик назначает **одного** ответственного сотрудника, уполномоченного
принимать решения по вопросам, возникающим в ходе работ, и указывает его в
Договоре.

**10.2.** Заказчик отвечает на письменные запросы Исполнителя в течение
**3 (трёх) рабочих дней**.

**10.3.** При нарушении сроков, установленных пунктами 10.2, 2.3, 3.3, 6.3,
срок выполнения соответствующего Этапа продлевается на количество дней
просрочки. Пеня за нарушение срока Исполнителем в этом случае не начисляется.

**10.4.** Для проверок, требующих участия сотрудников Заказчика (пункты 4.2.1–4.2.4,
7.2.3, 7.2.4), Заказчик обеспечивает их присутствие в согласованное время.

## 11. Гарантия

**11.1.** Исполнитель гарантирует работоспособность результата каждого Этапа в
соответствии с критериями приёмки настоящего Приложения в течение **6 (шести)
месяцев** с даты подписания Акта.

**11.2.** Недостатки, выявленные в гарантийный срок и представляющие собой
несоответствие критериям приёмки, устраняются Исполнителем безвозмездно в срок
не более **10 (десяти) рабочих дней** с даты письменного уведомления.

**11.3.** Гарантия не распространяется на случаи:
неработоспособности оборудования или каналов связи Заказчика; изменения
Заказчиком или третьими лицами исходного кода либо настроек Системы;
прекращения работы либо изменения условий сторонних сервисов (Telegram,
провайдер WhatsApp, почтовый сервис); утраты данных вследствие действий
сотрудников Заказчика.
